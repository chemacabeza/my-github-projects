# Java Master Class 2025 — Section 1: Getting Started with Java Programming

> **Course:** Java Programming Masterclass (2025 Edition)
> **Status:** Notes in progress

## Topics Covered

- JDK installation and IDE setup (IntelliJ IDEA)
- Understanding the Java compilation model (`javac` → bytecode → JVM)
- Writing and running your first `Hello, World!` program
- Java primitives, variables, and type system overview
- Basic operators and expressions
- Introduction to control flow (`if/else`, `switch`)
- Introduction to loops (`for`, `while`, `do-while`)

## Key Concepts

| Concept | Notes |
|---------|-------|
| `main` method | Entry point of every Java application: `public static void main(String[] args)` |
| Primitives | `int`, `long`, `double`, `boolean`, `char`, `byte`, `short`, `float` |
| `var` keyword | Local variable type inference (Java 10+) — use sparingly for readability |
| String literals | Immutable; `+` concatenates, `String.format()` / text blocks for complex cases |

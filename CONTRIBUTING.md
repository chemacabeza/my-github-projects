# Contributing to My GitHub Projects

## 👋 Welcome!

Thank you for your interest in this repository! This is primarily a **personal portfolio** and **learning archive** showcasing my professional work and educational journey across AI, Bash scripting, and Java/Spring Boot development.

## 🎯 Repository Purpose

While this repository serves mainly as a personal showcase, I welcome:

- ✅ **Bug reports** - If you find errors in documentation or code
- ✅ **Typo corrections** - Spelling and grammar fixes
- ✅ **Suggestions** - Ideas for improving clarity or organization
- ✅ **Questions** - Feel free to start a discussion if you have questions about the content

## 🤝 How to Contribute

### Reporting Issues

If you find a problem:

1. Check if an issue already exists
2. Open a new issue with:
   - Clear description of the problem
   - Steps to reproduce (if applicable)
   - Expected vs. actual behavior
   - Screenshots or code snippets if relevant

### Suggesting Improvements

For suggestions or feature requests:

1. Use **GitHub Discussions** for general ideas
2. Use **Issues** for specific, actionable improvements

### Pull Requests

Small improvements are welcome! For larger changes:

1. Open an issue first to discuss your idea
2. Fork the repository
3. Create a feature branch (`git checkout -b feature/your-feature`)
4. Make your changes
5. Test that everything works
6. Submit a pull request with a clear description

**Note:** Since this is a personal learning archive, not all suggestions may be accepted. The repository reflects my learning journey and professional work style.

## 📋 Code of Conduct

### Expected Behavior

- Be respectful and constructive in all interactions
- Provide helpful feedback when reviewing or commenting
- Respect that this is a personal portfolio repository
- Keep discussions professional and on-topic

### Unacceptable Behavior

- Harassment, discrimination, or personal attacks
- Spam or off-topic content
- Trolling or deliberately inflammatory comments

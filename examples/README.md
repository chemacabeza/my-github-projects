# Quick-Start Examples

This directory contains minimal, runnable examples demonstrating key concepts from each section of the repository.

## 📂 Contents

### 🎨 [ai-simple/](ai-simple/)
Simple AI image generation examples showing how to use the Fooocus models programmatically.

- **File**: `simple_generation.py`
- **Purpose**: Minimal example of generating an image with Fooocus
- **Prerequisites**: Python 3.10+, Fooocus installed

### ⚡ [bash-template/](bash-template/)
Practical Bash script templates following best practices from the Bash In Depth guide.

- **Files**:
  - `script-template.sh` - Production-ready script template
  - `argument-parser.sh` - Command-line argument parsing
  - `error-handling.sh` - Error handling patterns
- **Purpose**: Copy-paste templates for real-world scripts
- **Prerequisites**: Bash 4.0+

### ☕ [java-minimal-api/](java-minimal-api/)
Minimal Spring Boot REST API demonstrating core concepts.

- **Purpose**: Simple REST endpoint with Spring Boot
- **Features**: Single controller, basic configuration, ready to run
- **Prerequisites**: Java 17+, Maven 3.6+

## 🚀 Quick Start

Each example is self-contained and can be run independently:

```bash
# AI Example
cd examples/ai-simple
python simple_generation.py

# Bash Examples
cd examples/bash-template
bash script-template.sh --help

# Java Example
cd examples/java-minimal-api
./mvnw spring-boot:run
```

## 💡 Purpose

These examples serve as:
- **Quick validation** that your environment is set up correctly
- **Starting templates** for your own projects
- **Learning aids** showing minimal implementations
- **Reference code** demonstrating best practices

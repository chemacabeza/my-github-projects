# Section 8: Troubleshooting Fooocus

## Cannot connect to GPU backend

This happens when you run out of credits

## You are using Fooocus and then at some point you start to see "error" messages

This happens when you are disconnected from Fooocus and this means that you need to restart Fooocus or reconnect.

This happens a lot when you are using the Google Colab notebook for a long period of time.

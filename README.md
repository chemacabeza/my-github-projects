## 🌟 Featured Projects

### 🎨 AI Image Generation Platform
Production-ready **Fooocus** deployment with comprehensive model library for professional AI image generation.

- **Tech Stack**: Python 3.12, PyTorch, Docker, CUDA/MPS GPU acceleration
- **Model Library**: 7 SDXL checkpoint models + 15 LoRA fine-tuning models (46GB total)
- **Key Features**: Apple Silicon optimization, symbolic link model management, Docker containerization
- **Highlights**: Multi-style generation (realistic, anime, photography, Chinese style), character personalization
- **[Explore AI Projects →](AI-related/README.md)**

### ⚡ Bash In Depth: The Complete Guide
Comprehensive **35-chapter guide** to advanced Bash scripting - from fundamentals to production patterns.

- **Tech Stack**: 236 shell scripts, 35 structured chapters across 7 parts
- **Coverage**: Variables, control flow, I/O redirection, functions, process management, advanced topics
- **Key Features**: Hands-on examples, practical exercises, production-ready patterns
- **Highlights**: Complete learning path from basics to expert-level scripting techniques
- **[Learn Bash →](bash/README.md)**

### ☕ Enterprise Java Microservices
Full-stack **Spring Boot 3.x** applications demonstrating enterprise patterns and best practices.

- **Tech Stack**: Spring Boot 3, Spring Framework 6, Hibernate/JPA, Spring Security, MySQL
- **Coverage**: 10 sections from Spring Core to AOP, REST APIs, MVC, Security, Advanced Mappings
- **Key Features**: Layered architecture, dependency injection, security patterns, aspect-oriented programming
- **Highlights**: Production-ready microservices with comprehensive documentation
- **[View Java Projects →](JavaSpringBoot/README.md)**

## 🚀 Quick Start

Each section contains its own detailed setup instructions:

- **AI**: `cd AI-related && make run` (Docker) or `make install-local && make run-local`
- **Bash**: Navigate to `bash/chapters/` and explore the structured learning path
- **Java**: Individual Maven projects with `mvn spring-boot:run` in each subdirectory

# About This Repo

This repository is my personal **engineering toolbox**, where I collect and share projects, experiments, and hands-on tips across different technologies I work with every day. It’s not just a code dump—it’s a curated set of examples, utilities, and learning notes that showcase how I approach real-world problems. From backend development to automation and even creative tech, this repo reflects my passion for building, optimizing, and experimenting with modern tools.

**Java + Spring Boot** – Step into a backend powerhouse where Spring Boot projects are crafted like launchpads for future microservices. Here, RESTful endpoints and enterprise patterns come alive, hinting at APIs ready to scale, integrate, and wow. It’s a dynamic space where clean Java design meets the thrill of rapid experimentation, perfect for anyone eager to watch ideas evolve into production-ready services.

**Bash** – This is the beating heart of automation: a treasure trove of sharp, time-saving scripts that tame deployments, wrangle containers, and turbocharge daily tasks. Each Bash script feels like a secret shortcut, turning complex operations into single-command magic. Whether you love speed, elegance, or pure command-line power, this folder is an irresistible playground for scripting mastery.

**Fooocus** – Enter the creative frontier where code meets imagination. Fooocus unlocks the magic of AI-driven image generation, fusing Stable Diffusion wizardry with custom tweaks and experiments. From breathtaking visuals to daring generative art workflows, it’s the place where machine learning becomes an artist’s brush—perfect for anyone excited to create the spectacular out of pure code.
